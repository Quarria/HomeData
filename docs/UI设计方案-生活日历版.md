# 家常账 UI 设计方案：生活日历版

2026-10-17，用户确认首轮对比中的 06「生活日历 · 左侧导航」。本版替代原账页视觉，沿用既有费用、家庭权限、待办和报表规则。

## 视觉与页面

- 暖底 `#faf6f2`、莓红 `#833d50`、文字 `#4c2934`、辅助文字 `#796366`、浅表面 `#eee3df`、细分隔 `#e4d9d5`。
- 标题采用宋体回退，金额采用 Georgia，正文采用 Segoe UI／微软雅黑。工具界面以正常可读字号呈现，不用大块撞色或装饰图片。
- PC 固定 210px 左导航，窄桌面缩为 184px；手机使用五项底部导航，统一细线 SVG、浅莓红移动选中底板，保留文字。底栏预留安全区及页面底部空间。
- 首页保留快捷记录、最多三项近期事项、本月净支出。日期带由实际日期计算；事项按日期分组，包含七天内和逾期未处理项。日期带负责呈现分布，不新增日历管理。
- 桌面首页以日期时间线为主，右侧为月摘要和记录入口；手机先呈现三项紧凑快捷记录，再呈现日历事项，摘要放在其后。
- 账本以白色账页、行分隔、金额右对齐组织；待办区分普通待办和固定费用；报表保留现有统计口径、趋势、分类及明细；我的按账号、提醒、家庭和权限组织。
- 原型与正式应用同步视觉，但原型仅用于浏览、内存交互和设计核验，不代表后端服务。

## 动效

| 场景 | 实现 |
| --- | --- |
| 首页首次进入 | 日期和事项轻移 6px、淡入；右侧晚 50ms 跟上。每个账号在本次页面会话首次一次；空间切换不重播首次出场 |
| 导航与空间 | PC／手机导航使用同一块移动选中底板；个人／家庭使用莓红滑块。主区短淡入淡出，旧页退出即禁用交互，避免快速点击误作用于正在离开的页面 |
| 按钮 | 立即按压至 0.985，松手恢复；悬停只改变颜色和边界 |
| 记账及待办弹层 | 遮罩淡入，表单由 10px 下方进入；关闭沿反方向退出。键盘焦点进入表单、Tab 限定在窗口，关闭返回可用入口 |
| 保存与事项 | 服务端确认后显示结果；金额淡变、完成事项短暂退出、剩余事项补位。失败保留输入，不以动画伪造成功 |
| 减少动态效果 | 取消位移、缩放和过渡，直接显示状态，保留结果和错误信息 |

## 实现边界

正式应用新增首页组件，调用现有报表、待办和周期费用接口；记账、票据识别、创建待办与付款复用现有业务页面和表单。首页在空间切换时清空上一空间数据，忽略过期响应，避免显示混淆。

未引入新的服务、图片生成、付费资源或业务后端；没有执行生产构建、部署或真实 AI 调用。票据识别和真实数据仍需要已有后端服务配置。

## 验证与评审

正式应用类型检查与 lint 通过。定向 Playwright 测试使用受控 API 响应，覆盖桌面与手机五页、五项图标、320px 布局、失败保留输入、保存后刷新读回、事项完成、快速切换时过期响应隔离和减少动态效果。它们验证前端行为，不替代真实数据库及生产接口验收。

主代理另行走通原型 1440／768／390／320 四种宽度下五页导航、记账与金额联动、完成待办及减少动态效果；刷新恢复演示数据，符合其内存原型边界。

独立视觉评审初轮 7/10，修正家庭归属复选区、报表日期轴及手机期间箭头分组后复核 8/10，当前可见截图中无剩余必须修正项。另将“修改密码”操作沿左侧内容线对齐，减少手机动作位置零散。记录见 `deliverables/life-calendar/visual-review.md`。

减法：移除介绍页宣传口号、我的页面重复英文眉标、重复的空间／页面副标题及零退款的冗余金额说明；手机快捷操作说明缩短。保留对象、统计口径、归属可见性、状态和主动作。

证据位于 `deliverables/life-calendar/app-evidence/`、`prototype-evidence/` 和 `final-evidence/`。动效探测观察到首次出场与表单进入的位移／透明度变化；桌面和手机另存 2 倍密度截图。环境缺少 ffmpeg，已保存关键帧，未生成正常速度视频，不能声称完成录屏验收或提供帧率评分。

重看演示：运行 `node prototype/server.cjs`，访问 `http://127.0.0.1:4173/`。正式应用按项目既有开发流程启动并登录。
