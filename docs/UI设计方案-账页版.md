# 家常账 UI 设计方案：账页版

> 历史版本。2026-10-17 用户已改选「06 生活日历 · 左侧导航」，后续视觉以《UI设计方案-生活日历版.md》为准。

状态：第一版 UI 与交互原型已于 2026-10-15 经用户确认。既有功能规则继续以需求设计 1.2 为准；进入技术路线设计，正式开发尚未开始。

## 设计概念

把个人付款与家庭共享边界明确的日常记录，组织成一张可以核对、可以处理的账页。金额是主要视觉焦点，纸面与文字对齐建立层级，记账为主要操作。保留首页三块，不重新堆入图表或账单。

## 视觉系统

| 项目 | 设计 |
| --- | --- |
| 背景 | 石色 #eeecea |
| 内容纸面 | #faf9f7 |
| 辅助表面 | #e4e1dd |
| 主要文字 | 炭黑 #333231 |
| 操作色 | 灰绿 #526349 |
| 次要文字 | #68635e，保持阅读对比度 |
| 数字与拉丁字 | 本地 Bricolage Grotesque 可变字体 |
| 中文 | 系统 Microsoft YaHei 回退 |
| 字号 | 五级规模：13、16、22、40、76 px；手机标题 32、主金额 44 px |
| 图标 | 本地统一线条 SVG，导航、账本、任务与票据一致 |
| 表面 | 色面区分，不使用静止阴影、玻璃模糊、渐变或装饰性细框 |
| 动效 | 按压反馈、账页进场、弹窗进场；仅 transform/opacity，支持减少动态效果 |

纸面下缘只用于开支摘要，来源于票据；不把纹理或图案堆到所有模块。没有添加不相关的摄影或营销内容。

## 各页交互与布局

- 首页：默认个人，大金额摘要、主要记账动作、次要拍票据和待办动作、最多三项近期事项。电脑左右编排，手机按摘要、记录、处理顺序单列。
- 账本：纸面列表、金额对齐、归属筛选和分类筛选；保留单条详情、退款和购物分组。
- 待办与提醒：待办任务／固定费用切换，状态、完成者与付款人清晰显示。
- 报表：净支出、支出、退款采用明确层级，趋势与分类只在本页展示，水电燃气继续独立统计。
- 我的：按账号、家庭、分类和分享组织，管理功能依角色展示。
- 记账弹窗：金额、分类、名称与归属优先，补充信息展开，可见范围始终清楚。
- 票据核对：汇总先行、展开明细，批量归属与补充已有凭证两条路径保留。

金额、姓名、日期和票据均为原型演示数据。账号、微信与 AI 服务未实际接通；配色与临时页面代码不代表正式技术框架已确定。

## 界面验收与实现要求

第一版视觉与交互已于 2026-10-15 确认。桌面、平板和手机使用同一视觉系统；正式实现需补齐真实账号、权限及外部服务状态。

- 在 1440、768、390、320 px 下检查五个页签及记账表单，无页面横向溢出。
- 核验再记／撤销、可见性提示、购物分组、补充凭证、完成者和付款人、分析依据跳转。
- 提供减少动态效果支持，字号、对比度与操作目标满足可读性要求。
- 原型演示不替代真实数据、权限、AI和微信渠道验收；开发及验收细则见《家常账-开发技术文档》。
