# 家常账原型设计：第一轮

状态：第一版整体原型已于 2026-10-15 经用户确认。需求设计 1.2 已确认；进入技术路线设计，技术方案尚未选定，正式开发尚未开始。

## 首页调整

用户指出原三种首页与完整功能页重复，已确认收敛为一个日常入口，不再比较 A／B／C。

默认进入个人空间，用户可主动切换家庭；页签之间沿用当前空间，新建操作默认沿用当前选择。

| 区块 | 内容 | 边界 |
| --- | --- | --- |
| 快捷记录 | 记一笔、拍票据、新建待办 | 直接进入对应流程 |
| 近期需处理 | 逾期、今天到期和近期事项，最多 3 项 | 查看任务详情或确认缴费；全部事项进入待办与提醒 |
| 本月开支摘要 | 一个净支出金额及查看报表入口 | 不展开完整统计分析 |

保留已确认的五项导航：首页、账本、待办与提醒、报表、我的。第三项分为待办任务和固定费用。电脑侧边导航，手机底部导航。首页不展示完整趋势、分类排行、水电燃气图和最近账单列表；无待处理事项时展示完成状态。原型中“近期”暂按未来 7 天与全部逾期事项计算。

## 原型中的可体验流程

- 切换个人与家庭；个人费用再筛选全部、个人归属和家庭归属。
- 手动记账、编辑、记录详情、原支出关联退款、删除与恢复。
- 票据识别示例核对与逐条确定归属。
- 新建待办、完成与重新打开；新增固定费用、暂停、跳过、确认支付。
- 固定费用付款记录删除／恢复与本期状态联动。
- 日月年报表、分类明细、水电燃气独立趋势。
- 主动生成示例分析、查看本人历史、删除分析。
- 汇总分享预览、撤销、家庭归档与管理员交接。

## 本轮体验优化

轻量记账默认只需金额、分类和名称，补充字段可展开，可见范围随归属实时提示；保存后可再记、短暂撤销。个人空间说明本人付款包含家庭费用。

票据按一次消费核对，支持汇总／展开、批量归属、新建或补充已有凭证，账本分组成组显示。完成任务显示完成者，付款显示付款人，账目详情可查看操作历史。分析按变化、依据和待核对展示，计算差额并可核对明细。

水电燃气不增加专用输入，使用通用数量、单位，保持独立金额趋势。

## 演示边界与服务接入

数据在内存中，刷新后重置。票据识别与分析使用示例，不调用真实 AI。微信、账号和密码管理、通知与额度设置仅展示入口，未接通实际服务。分享仅预览，不生成外部链接。当前并非完整产品实现，不代表已实现服务端权限、持久化或定时推送。

使用的临时页面代码仅用于原型评审，不构成正式技术路径决策。

## 核验与待确认

新版首页和五个页签在 1440、390、320 像素宽度下无页面横向溢出或脚本错误。已核对三个快捷入口、最多三项提示、处理完全部五项示例事务后的完成状态，以及新增任务、快捷记账、报表和全部事项跳转。此前已核对退款恢复、固定费用支付、归档拦截、个人任务空间隔离、个人归属金额和管理员交接对象。

体验优化已核验：补充字段默认折叠、单价数量计算、归属提示、保存不自动切换空间、再记与短暂撤销、混合票据批量与单项归属、家庭分组金额不含个人条目、补充已有凭证不新增账目、完成者和付款人，以及分析差额、证据期间与明细跳转。模拟数据计算的电费下降 27.40 元可核对，不据此猜测原因。
