# 家常账 · 网格手账风格预览

- 目标：参考用户提供的 3.jpg、4.jpg，先设计一个总览页，以便确认整站视觉方向。
- 设计方向：米白网格纸、粗黑描边、硬投影；青色用于记账主操作，黄色用于日期与待处理标记。保持支出、近期事项、固定费用的信息顺序。
- 范围：独立 HTML 原型，不修改 Vue 正式业务组件。所有金额与事项为演示数据，新增记录仅保留在当前页面内存中。
- 交互：记账弹窗、金额更新、明细列表、待办勾选、票据选择；AI 识别未接入。其余导航尚未实现完整页面。
- 动效：首次入场、按钮按压、待办状态反馈；尊重减少动态效果设置。
- 验证：已实际查看约 440px 窄屏，验证新增 25 元后总额为 3311.50。桌面布局已实现，未实际截图验证。未做独立评审；自主检查一轮。文案初稿保持简短，未额外删减。
- 证据：preview.png。启动：在仓库根目录运行 node prototype/paper-home/server.cjs，访问 http://127.0.0.1:4185。

## 第二轮：标题、字体与配色
- 修复：取消绝对定位的外扩旋转色块；改用文字自身背景，文字和背景不再通过负层级叠放。取消标题负字距。
- 字体：优先使用本机等线及其粗体；标题从 900 调至 700，增加行高；英文辅助信息改为无衬线。
- 配色：顶部提供暖黄墨黑、奶黄鼠尾草、明黄雾蓝、鹅黄杏桃四种切换；每种都保留黄色重点标记。
- 验证：窄屏实际查看修正后的标题；鼠尾草、雾蓝切换成功并查看画面。杏桃切换状态成功，但后续截图调用遇到自动审批服务 403，未取得最终截图，未继续操作浏览器。桌面未实测。

## 已确认的配色决定
四套配色全部保留供日常切换。首次默认明黄 × 雾蓝；用户切换后以浏览器 localStorage 记住选择，下次打开恢复。存储不可用时仍可切换，首次回退雾蓝。本次落实于独立原型，正式 Vue 网站尚未迁移。
